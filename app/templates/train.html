ℹ️ About the Model

This system trains a transformer-based multi-label classifier to categorize IFS activities into four dimensions:

  • Phase - Project phase (FEED/Study, Construction, Engineering, etc.)
  • Discipline - Engineering discipline (Piping, Electrical, Mechanical, etc.)
  • Work Type - Type of work (Engineering, Fabrication, Management, etc.)
  • Location - Work location (Offshore, Onshore, Yard, etc.)

The model learns from the activity descriptions combined with contextual features like discipline codes, phase prefixes, and project categories.

Training Tips:

  • More diverse training data generally leads to better generalization
  • Imbalanced labels may need oversampling or class weights
  • Start with default hyperparameters, then tune if needed
  • Watch for overfitting if training loss decreases but validation loss increases
