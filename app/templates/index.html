About the Project

This application helps migrate legacy IFS10 activities to the new IFS Cloud project structure. Using state-of-the-art transformer models (RoBERTa BigBird), it learns from historical mappings to automatically classify new activities.

Features:

  • Oracle Database integration for data retrieval
  • CSV file upload support
  • RoBERTa BigBird transformer model training
  • Real-time training progress monitoring
  • Batch and single prediction capabilities
  • Model performance metrics and evaluation
